What it is

A desktop API client. The same job as Postman or Insomnia — compose a request, send it, read the response, keep the useful ones — with one difference that changes everything downstream: nothing leaves your machine unless you say so.

The whole HTTP surface

Every method, every body type, authentication, redirects, cookies, proxies, client certificates, cancellation mid-flight. Large responses stream to disk instead of eating your memory.

Not only HTTP

GraphQL, with a button that asks the endpoint for its schema. Server-sent events and websockets, picked from the same dropdown as the verbs — a connection keeps the URL, headers, variables and authentication the request already had, and opens a live transcript you can type into.

Variables that make sense

{{baseUrl}} resolves across workspace, collection, environment and request, nearest wins. Secrets go in your operating system's credential store — not the database, not an export, not a sync payload.

Bring what you already have

Imports OpenAPI 3, Postman collections and environments, and cURL commands. Exports to portable JSON, or copies any request back out as cURL.

Scripts and tests

JavaScript before a request and after a response, in a sandbox with no filesystem, network or process access. Write assertions; results appear beside the response.

OAuth 2.0 that works

Authorization code with PKCE through a loopback listener, client credentials, password grant. Tokens are held in memory and attached at send time — never written to the database, an export or a sync.

Everything you sent, kept

Every send goes into history with its response, so the one that worked an hour ago is still there to look at or replay. Ctrl‑K opens a palette that reaches any request, collection or environment without touching the mouse.

It opens quickly

Because it is a native window, not a packaged web browser. That is a consequence of how it is built rather than the reason to use it.

Measured, not claimed

Both applications sitting idle on the same machine, measured with scripts/measure-memory.sh in the repository. PSS — the honest number, which divides shared memory rather than counting it twice.

Built for a team that
would rather not have an account

One person needs no server at all, and Relay is whole without one. The moment a second person needs the same collections, you have a choice most API clients do not offer: run the server yourself, or let us run it. The software is identical either way.

What a team gets

  • The same collections on every machine, for everyone
  • Viewer, editor and admin roles, changed from inside the app
  • Invitations bound to the address they were sent to
  • Live updates over a websocket — no refresh button
  • Conflicts shown side by side, never silently resolved
  • Secrets that do not sync, because they never leave your keyring

A conflict is a question, not an accident. Relay shows you both versions and lets you pick; it never quietly overwrites work.

Run the server yourself

One small Rust binary, or a Docker image. SQLite for a single team, PostgreSQL if you prefer. No licence check, no seat count, no phone-home, no account with us — self-hosting is free for any number of people and depends on nobody, including us. 

docker run -p 8787:8787 \
  -e RELAY_DATABASE_URL=sqlite:///data/relay.db \
  relay-server

This is the path that was built first, and the one the whole design assumes. The hosted option below is the same software, running on somebody else's computer.

What it does

A lapsed card never holds your work hostage

If a payment fails, syncing keeps working. Reading keeps working. Exporting keeps working. The only thing that stops is adding another person, and your existing team is never locked out or locked down. A tool you keep your API requests in has no business taking them away over a card that expired.

And if you would rather not be billed by anybody at all, the self-hosted server has no seat limit and no billing in it.

An assistant that cannot read your secrets

Ask it to find a request, write a test, point a collection at staging — anything you could do yourself. Bring your own API key and it talks straight from your machine to the provider you pick; or let the team plan carry it and nobody has to find a key at all. Either way its conversations live in the same local database as everything else.

Your key, your provider

Claude, OpenAI, or anything speaking the same shape — Ollama and LM Studio included, so the whole thing can run on your own machine. Your own key is free, unmetered and never counted, on every plan including the free ones.

Or no key at all

On Team + Assistant the server holds the key, so nobody on the team has to find one, pay a second bill or paste a credential into a settings box. A thousand requests a person a month; past that your own key picks up, free, as it always was.

It asks before it acts

Sending a request and deleting something always need your say-so, inline, before they happen. A request the assistant sends is indistinguishable at the far end from one you sent — so you get asked.

Secrets stay invisible to it

It can see that a variable called apiSecret exists. It cannot see the value, and credential-shaped headers come back redacted. An agent can be steered by whatever it just read on a web page; it is not a safe place for a password.

Your own tools, too

Point it at an MCP server you run and its tools appear beside Relay's own. Anything someone else's tool offers is always confirmed before it runs.

The conversations stay with you

In the same SQLite file as your requests, on your disk, searchable and deletable by you. A tool whose whole argument is that your data is yours cannot answer where do my conversations live with somebody else's cloud.

Starting a team

Three steps, and the first person pays nothing. Invite the second when there is a second.

  1. Create an account — an address and a password, nothing else.
  2. Install Relay and open Sync.
  3. Give it this address: https://relay-sync-ct0w.onrender.com

It idles when nobody is using it, so the first request after a quiet spell takes a moment to wake. Your edits queue meanwhile and nothing is lost.

Then invite someone

Sync → Members → Invite, with a role. They get a link, pick a password, and land in the workspace with everything already in it. The invitation only works for the address it was sent to, so a forwarded email is not a way in.

Adding the second person is the moment a card is needed. Nothing before that asks for one, and there is no trial to run out.

Get Relay

Download it and run it, the way you would run anything else. Or build it yourself in one command, if you would rather not trust a binary you did not compile — both are supported and neither is the lesser path.

Linux .deb .rpm .AppImage macOS .dmg Windows .msi .exe

Or build it

git clone https://github.com/l-robinsonl/relay
cd relay
npm install
npm run tauri build

Needs Rust and Node. The installers land in src-tauri/target/release/bundle, and the binary beside them in target/release.

First run on macOS and Windows

The downloads are not code-signed yet, so both will stop you once. On macOS, right-click the application and choose Open the first time, or clear the flag: 

xattr -dr com.apple.quarantine /Applications/Relay.app

On Windows, choose More info then Run anyway. Linux is unaffected. Certificates are the hold-up rather than anything in the code — building it yourself sidesteps this entirely.
